# Wage Tracker 💰

Wage Tracker is a personal wage management application designed to simplify the process of recording daily earnings and analyzing wage patterns.

The app transforms daily wage records into useful insights, helping users understand their earnings through statistics and summaries.

## Features

- **Daily Wage Tracking** — Record and manage daily wage entries.
- **Average Wage Analysis** — Calculate average earnings.
- **Highest & Lowest Earnings** — Identify the highest- and lowest-earning days.
- **Earnings Statistics** — View useful summaries of recorded wages.
- **Income Insights** — Understand earnings patterns over time.

## Purpose

This project was built to make tracking daily wages easier and to turn wage records into meaningful, easy-to-understand insights.
